                         WHAT TO DO BEFORE BUILD
════════════════════════════════════════════════════════════════════════════

TASK 1: CREATE KEYSTORE (Do this first!)
────────────────────────────────────────────────────────────────────────────
Command:
    cd D:\NEW_PROJECTS\Habitera\android
    keytool -genkey -v -keystore habitera_release.jks `
      -keyalg RSA -keysize 2048 -validity 10000 `
      -alias habitera_release_key

When asked, enter:
    Keystore password: ________________ (save this!)
    Key password: ________________ (same as above is fine)
    First and last name: Your Name
    Organization: Your Company
    Country code: US

Result: Creates habitera_release.jks file


TASK 2: CONFIGURE CREDENTIALS
────────────────────────────────────────────────────────────────────────────
File: android/key.properties

Replace:
    storePassword=YOUR_STORE_PASSWORD

With:
    storePassword=THE_PASSWORD_FROM_TASK_1

Replace:
    keyPassword=YOUR_KEY_PASSWORD

With:
    keyPassword=THE_PASSWORD_FROM_TASK_1

Leave these alone:
    keyAlias=habitera_release_key
    storeFile=habitera_release.jks


TASK 3: UPDATE PACKAGE NAME
────────────────────────────────────────────────────────────────────────────
Decide your package name (examples):
    ☐ com.mycompany.habitera
    ☐ com.myname.habitera
    ☐ io.github.username.habitera

File 1: android/app/build.gradle.kts
    Find: applicationId = "com.example.habitera"
    Replace with: applicationId = "com.mycompany.habitera"

File 2: android/app/src/main/AndroidManifest.xml
    Find: <manifest xmlns:android="http://schemas.android.com/apk/res/android">
    Replace with:
    <manifest xmlns:android="http://schemas.android.com/apk/res/android"
        package="com.mycompany.habitera">

⚠️ USE SAME PACKAGE NAME IN BOTH FILES!


TASK 4: VERIFY VERSION (Usually no change needed)
────────────────────────────────────────────────────────────────────────────
File: pubspec.yaml
    Current: version: 1.0.0+1
    Status: ✓ OK for first release
    
If updating: Change to 1.0.1+2 (increment both numbers)


TASK 5: RUN BUILD COMMANDS
────────────────────────────────────────────────────────────────────────────
Command 1:
    flutter clean

Command 2:
    flutter pub get

Command 3:
    flutter analyze

Command 4:
    flutter test

Command 5:
    flutter build appbundle --release

Wait 3-5 minutes for build to complete...

Result: 
    ✓ BUILD SUCCESSFUL
    File: build/app/outputs/bundle/release/app-release.aab
    Size: ~20-25 MB

                          TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════

IF: Build fails with "Keystore not found"
FIX:
    1. Check habitera_release.jks exists in android/ folder
    2. Verify key.properties has correct path
    3. Re-run: flutter build appbundle --release

IF: "Wrong password" error
FIX:
    1. Verify passwords in key.properties match keystore
    2. Check for extra spaces
    3. Regenerate keystore if needed

IF: Build fails with gradle error
FIX:
    1. flutter clean
    2. flutter pub get
    3. flutter build appbundle --release

IF: File not found when editing
FIX:
    1. Open VS Code
    2. Click File > Open Folder
    3. Select: D:\NEW_PROJECTS\Habitera
    4. Use Ctrl+P to find files
    5. Edit and save
