================================================================================
                        TROUBLESHOOTING REFERENCE
================================================================================

ISSUE: "Gradle build failed"
SOLUTION:
  1. flutter clean
  2. flutter pub get
  3. Check Java version: java -version (should be 11+)
  4. Check Android SDK: flutter doctor -v

ISSUE: "Keystore not found"
SOLUTION:
  1. Verify habitera_release.jks exists in D:\NEW_PROJECTS\Habitera\android\
  2. Check key.properties path is correct
  3. Ensure file not hidden

ISSUE: "Wrong password" during build
SOLUTION:
  1. Verify passwords in key.properties match keystore
  2. Test with: keytool -list -v -keystore android/habitera_release.jks
  3. Regenerate keystore if needed

ISSUE: "Build errors"
SOLUTION:
  1. Run: flutter analyze
  2. Run: flutter test
  3. Fix all reported issues
  4. Rebuild

ISSUE: "Cannot upload to Play Store"
SOLUTION:
  1. Verify app.release.aab file exists
  2. Check file size is ~20-25 MB
  3. Ensure developer account is active
  4. Check content rating completed
