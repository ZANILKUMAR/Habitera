## 🚀 3-Step Quick Start

### 1️⃣ Create Keystore (5 min)
```powershell
cd D:\NEW_PROJECTS\Habitera\android
keytool -genkey -v -keystore habitera_release.jks `
  -keyalg RSA -keysize 2048 -validity 10000 `
  -alias habitera_release_key
```

### 2️⃣ Configure Credentials (2 min)
```properties
# Edit: android/key.properties
storePassword=YOUR_PASSWORD
keyPassword=YOUR_PASSWORD
keyAlias=habitera_release_key
storeFile=habitera_release.jks
```

### 3️⃣ Build App Bundle (5 min)
```powershell
cd D:\NEW_PROJECTS\Habitera
flutter clean
flutter pub get
flutter build appbundle --release
```

✅ **Done!** Find your app at: `build/app/outputs/bundle/release/app-release.aab`
